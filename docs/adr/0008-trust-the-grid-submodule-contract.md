# Trust the Grid Submodule Contract

Grid Inspection design and implementation will treat the submodule author's stated behavior as the upstream contract: non-empty `pred_text_L` is a `table_size`-shaped row-major matrix, unrecognized or padded cells contain `"N/G"`, smaller requested dimensions crop the result, and an uninspectable image returns an empty list. The Gateway currently points to submodule commit `d3e5c06` (tag `2026.08.03`), which keeps the `procd_table`/`procd_table_L` interfaces while refining area cropping and row grouping. Its single-cell `get_maplist_v2_single_L` path now wraps the detected value as `[pred_text]`, so `table_size=[1,1]` follows the same list-of-lists response contract as larger Grid tables. API Gateway will not reconstruct or compensate for upstream detection behavior; real-model conformance beyond the deployed smoke test remains unverified rather than blocking the Gateway work.
